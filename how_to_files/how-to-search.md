## How-to: use the search
One of the main features of the database is the set of candidate mimicry-peptides which are displayed as a customisable table in the “Peptide Search” section. Users can search on three fields using the search bar in the filters side bar. Typing into the text box searches on peptide sequence, microbial organism name, and human gene symbol. This is the main search functionality. 

_Quick tip: MIMICRY uses the same free-text search box for peptide sequences, microbial organism names, and human gene symbols. For example, searching KRT can retrieve keratin-related gene records, while entering an amino-acid sequence searches for records containing that sequence and peptides with that as a sub-sequence as well._

### Searching using peptides 
Use a peptide sequence search when you have a peptide of interest and want to find matching records in MIMICRY.
1. Enter the peptide sequence in the Search field.
2. This will filter the table as you type. 
3. You can also search on a smaller part of your sequence if your full peptide doesn't match.

### Searching using genes 
Use a gene search when you want to find molecular mimicry records associated with a particular human gene with a cancer related mutation.
1. Enter the human gene symbol in the Search field.
2. If the gene is missing, you can try alternate names for that gene, or a short peptide sequence of that gene instead.
 
### Searching using organisms  
Use an organism search when you want to find molecular mimicry records associated with a particular microbial organism.
1. In the Search field, enter the name of the microbial organism of interest.
2. You can only search on Species/strain name here, but you can filter on the broader taxonomy in the filter side bar.
3. Filters work on "Kingdom", "Phylum", "Genus", and "Species". 

### Searching using filters  
Although the filters are good to refine your search, you can use these filters as a broader search tool. For most the filters, a text box will appear underneath the title once expanded. For some filters, there will be a drop-down menu, or check boxes.  
1. HLA-binding: filtering on "All", "Strong", or "Strong and weak" binders. These options are useful to narrow down your search by binding strength to the predicted HLA, providing more likely immunogeneic candidates.
2. Following from the previous filter, "Binding thresholds" allows the users to limit the HLA predictions to highly ranked alleles.
3. The "Antigen type" filter allows the user to focus on either "Neoantigens" or "Tumor-associated antigens". This ignores the "Normal" peptides found. Under "Neoantigens", one can also filter on mutation type including: "SNVs", "INDELs" or "Fusion" derived peptides. 
4. Cancer is the disease specific filter. This includes broad cancer types (e.g., "Breast cancer") or more specific sub-types (e.g., "HER2 negative breast cancer").
5. Sample tissue allows the user to filter by tissue, ignoring whether this is normal or cancerous tissues.
6. Antigen source is a filter on the database of origin for the peptides.
7. Microbe body site is a filter for the location of the microbial organisms. These locations come from the HMGRD, and are the most common microbiome locations.
8. The taxonomy filters, described previously, allow a broad organism search. 
9. The HLA allele filter allows users to filter on the 27 alleles used in the prediction tools.
